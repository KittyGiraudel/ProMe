ProMe collecte le minimum de données nécessaires à son fonctionnement. Cette page explique ce qui est collecté, pourquoi, et quels sont vos droits.

## Ce qui est collecté

**Sans compte**, vos données (personnages, carte, journal) restent intégralement dans le stockage local de votre navigateur. Rien n’est envoyé à un serveur.

**Avec un compte Google** (optionnel), ProMe collecte :

- Votre adresse e-mail et votre nom d’affichage Google pour identifier votre compte
- Vos données de personnage (personnages, cartes, journaux) synchronisées dans une base de données cloud pour y accéder depuis plusieurs appareils

## Pourquoi est-ce collecté

Les données d’authentification (e-mail, nom d’affichage) servent uniquement à relier vos données cloud à votre compte. Les données de personnage ne sont stockées à distance que si vous avez activé la synchronisation cloud.

## Combien de temps est-ce conservé

Vos données sont conservées tant que votre compte existe. Pour les supprimer, ouvrez un ticket sur [GitHub](https://github.com/KittyGiraudel/ProMe/issues) et vos données seront effacées rapidement.

## Services tiers

ProMe repose sur les services suivants :

- **Google** : authentification (OAuth). [La politique de confidentialité de Google](https://policies.google.com/privacy) s’applique.
- **Netlify** : hébergement et gestion des identités. [La politique de confidentialité de Netlify](https://www.netlify.com/privacy/) s’applique.
- **Neon** : hébergement de base de données. [La politique de confidentialité de Neon](https://neon.tech/privacy-policy) s’applique.

Aucune donnée n’est vendue ni partagée avec des tiers à des fins publicitaires.

## Vos droits

Si vous résidez dans l’Union européenne, vous disposez du droit d’accéder à vos données personnelles, de les corriger ou de les supprimer à tout moment. Contactez moi sur GitHub pour exercer ces droits.

## Aucune garantie

ProMe est un projet personnel proposé gratuitement, sans aucune garantie de disponibilité, de continuité ou d’adéquation à un usage particulier.
