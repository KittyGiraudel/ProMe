# Self-hosted biome title fonts

**Date:** 2026-04-15
**Status:** Approved

## Problem

Biome pages load custom title fonts from `fonts.googleapis.com` at runtime. This breaks offline use (PWA) and introduces a runtime CDN dependency. The current approach passes `&text=` to Google Fonts for character subsetting, which is already tight, but the result is never cached locally or bundled with the app.

## Solution

Download the minimal WOFF2 subsets once, commit them to the repo, and load them via static CSS. A generator script reproduces the files whenever fonts change.

## Biome fonts and character sets

| Biome | Font | FR title | EN title |
|---|---|---|---|
| shadowForest | Caesar Dressing | La Forêt des Ombres | The Shadow Forest |
| mushroomJungle | Shizuru | La Jungle de Champignons | The Mushroom Jungle |
| floodedPlains | Rubik Marker Hatch | Les Plaines Inondées | The Flooded Plains |
| titanGardens | Mountains of Christmas | Les Jardins Titanesques | The Titan Gardens |
| fieldSea | Mystery Quest | La Mer Champêtre | The Sea of Fields |
| silentDesert | Fredericka the Great | Le Désert Silencieux | The Silent Desert |

Characters used per font are the union of the FR and EN title strings, deduplicated.

## Script: `scripts/subset-biome-fonts.mjs`

A single Node script (no extra npm dependencies). Run with:

```sh
node scripts/subset-biome-fonts.mjs
```

For each biome font:

1. Build the minimal character set: combine FR + EN title strings, deduplicate.
2. Fetch `https://fonts.googleapis.com/css2?family=<family>&text=<encoded>&display=swap` with a modern `User-Agent` header (required to receive WOFF2 instead of TTF/WOFF).
3. Parse the CSS response to extract the WOFF2 `url(...)`.
4. Download that WOFF2 to `public/fonts/biomes/<kebab-name>.woff2`.
5. Accumulate `@font-face` declarations referencing `/fonts/biomes/<file>.woff2`.
6. Write all declarations to `src/components/PageBiome/biome-fonts.css` with a "do not edit — run script to regenerate" header.

Font + character data lives in the script as a plain object. Adding a new biome font = edit the object, re-run the script.

## File layout

```
scripts/
  subset-biome-fonts.mjs          # Generator script
public/
  fonts/
    biomes/
      caesar-dressing.woff2
      shizuru.woff2
      rubik-marker-hatch.woff2
      mountains-of-christmas.woff2
      mystery-quest.woff2
      fredericka-the-great.woff2
src/
  components/
    PageBiome/
      biome-fonts.css             # Auto-generated @font-face declarations
      BiomePage.css               # Gains static per-biome font-family rules
      BiomePage.tsx               # Imports biome-fonts.css
```

## CSS changes

### `biome-fonts.css` (auto-generated)

```css
/* Auto-generated by scripts/subset-biome-fonts.mjs — do not edit manually. */
@font-face {
  font-family: 'Caesar Dressing';
  src: url('/fonts/biomes/caesar-dressing.woff2') format('woff2');
  font-display: swap;
  font-style: normal;
  font-weight: 400;
}
/* … one block per font … */
```

### `BiomePage.css` additions

Static per-biome rules (currently injected as an inline `<style>` from `page.tsx`):

```css
.BiomePage[data-biome='shadowForest'] .BiomeHero__title { font-family: 'Caesar Dressing', serif; }
.BiomePage[data-biome='mushroomJungle'] .BiomeHero__title { font-family: 'Shizuru', serif; word-spacing: -40px; }
.BiomePage[data-biome='floodedPlains'] .BiomeHero__title { font-family: 'Rubik Marker Hatch', serif; }
.BiomePage[data-biome='titanGardens'] .BiomeHero__title { font-family: 'Mountains of Christmas', serif; }
.BiomePage[data-biome='fieldSea'] .BiomeHero__title { font-family: 'Mystery Quest', serif; }
.BiomePage[data-biome='silentDesert'] .BiomeHero__title { font-family: 'Fredericka the Great', serif; }
```

## `page.tsx` simplification

Remove entirely:
- `<link rel='preconnect' href='https://fonts.googleapis.com' />`
- `<link rel='stylesheet' href={...Google Fonts URL...} />`
- The inline `<style>` block with `font-family` and `word-spacing`
- The `fontConfig` variable and `BIOME_FONTS` import

The component body becomes simply `<Page biome={biomeId} />`.

## `misc.ts` cleanup

`BIOME_FONTS` has no remaining callers after the above changes and is deleted.

## How to add a new biome font in future

1. Edit the font data object in `scripts/subset-biome-fonts.mjs` — add the biome id, font family name, FR title, EN title.
2. Run `node scripts/subset-biome-fonts.mjs`. This downloads the WOFF2 and regenerates `biome-fonts.css`.
3. Add the `font-family` rule for the new biome to `BiomePage.css`.
4. Commit the new WOFF2, updated CSS files, and the updated script.
