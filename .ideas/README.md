# Ideas

This directory contains feature ideas for the application: each feature has its own Markdown file with context, goal and open questions. They cannot be tackled in any order: some features need to be done before others because they depend on one another. When relevant, a feature document may contain requirements.

## Instructions

Whenever implementing an idea:

- When in doubt: ask questions.
- Make components small and atomic.
- Extract logic in small hooks and functions — make components as dumb as possible.
- If necessary, udpate the README with new documentation.
- If necessary, update existing documentation to reflect the new information.
- Add as many unit tests as relevant, covering the most important bits of core logic. Unit tests are cheap and efficient, so they should be used.

[^1]: The documentation is largely for AI agents in order to build context and understanding of what the idea is for.
